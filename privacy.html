Custom Spam Filter

Privacy policy

Effective October 30, 2026

Custom Spam Filter is a private local helper operated by Brett Bilon. Its Google connection is used to save and verify Gmail sender-blocking rules for accounts authorized by the owner.

Information used

The helper uses the authorized account's verified email address, the selected sender address or domain, configured exceptions for approved correspondents, Gmail filter criteria and identifiers, and Gmail label names and identifiers. Thunderbird provides sender information and handles the owner's existing local mailbox cleanup.

The Google authorization requests account identity, Gmail settings and filter management, and Gmail label management. It does not request email-body reading or email-sending permission.

Storage and sharing

Authorization tokens and rule records are stored on the owner's computer in private local files. Tokens are not included in the source repository, build sandbox, public website or application logs. The helper sends necessary rule and label information to Google to carry out the requested mailbox changes.

The helper does not sell Google user data, share it with advertising or analytics services, or use it to train artificial intelligence models. Google user data is used only to provide the blocking feature, consistent with the Google API Services User Data Policy and its Limited Use requirements.

This information website is hosted on GitHub Pages. GitHub may process ordinary website request information under its own privacy policy. The website does not receive mailbox data, authorization tokens or filter requests, and contains no application analytics or tracking scripts.

Control and removal

The owner can revoke the helper's access in their Google Account permissions. Revocation prevents future updates by the helper. Existing Gmail rules continue to work until the owner deletes them in Gmail's Filters and Blocked Addresses settings. Local authorization and rule files can also be removed from the owner's computer.
